# Lyra-32 Sound Design Course

A musician’s course in synthesizer sound design. The lab instrument is [LYRA-32](https://raybridgedigital.github.io/lyra-32/). The course is the subject; LYRA is the bench.

Lessons C0–C22: signal path, envelopes, filter, FX, LFO, matrix, Shape, arp, groove, poly/mono/glide, dual layer, wavetable, hybrid, scenes, MIDI, bounce, voice budget, and an original bank.

Read it in the browser: [raybridgedigital.github.io/Lyra-32-SoundDesignCourse](https://raybridgedigital.github.io/Lyra-32-SoundDesignCourse/)

```bash
npm install
npm run dev
```

USB MIDI only. No computer-key fallback.
